# Amir Mohammad Asgari — Developer Portfolio

A personal developer portfolio hosted with GitHub Pages.

The website presents contact links, technical skills, and a terminal-inspired animated profile using HTML, CSS, and vanilla JavaScript.

## Live Website

[https://mr-amirasgari.github.io](https://mr-amirasgari.github.io)

## Features

- Terminal-inspired portfolio interface
- Animated code and output panels
- Responsive profile card
- Social and contact links
- Mobile and tablet layouts
- Lightweight static deployment
- No build process or JavaScript framework required

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Bootstrap 5
- Font Awesome
- GitHub Pages

## Run Locally

Clone the repository:

```bash
git clone https://github.com/mr-amirasgari/mr-amirasgari.github.io.git
cd mr-amirasgari.github.io
```

Open `index.html` directly in a browser, or start a local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deployment

Because the repository is named `mr-amirasgari.github.io`, GitHub Pages can publish it directly from the default branch.

## Privacy

Public portfolio pages should avoid exposing unnecessary personal information such as private phone numbers, full addresses, or birth dates.
